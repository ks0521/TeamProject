## 주요 기능

### 스테이지 전투 시스템

플레이어는 스테이지를 선택해 자동으로 전투를 진행하며, 스테이지는 일반 / 도전 / 보스 세 가지 유형으로 나뉩니다. 일반 스테이지는 플레이어가 사망해도 일정 시간 후 부활해 반복 사냥을 이어갈 수 있으며, 도전 스테이지는 제한 시간 내 목표 킬 수를 채우거나 보스를 처치해야 클리어할 수 있습니다. 몬스터는 오브젝트 풀로 관리되어 불필요한 생성/삭제 비용을 최소화했습니다.

### 보상 시스템

몬스터 처치 시 `DropTableSO`에 정의된 확률에 따라 재화와 장비가 드랍되며, 도전/보스 스테이지 클리어 시에는 `RewardTableSO` 기반의 클리어 보상이 별도로 지급됩니다. 또한 게임을 종료한 뒤 다시 접속했을 때 오프라인으로 경과한 시간을 계산하여 그에 맞는 보상을 자동으로 지급하는 오프라인 접속 보상 시스템도 구현되어 있습니다.

### 성장 시스템

- **스탯 강화** : 사냥 시 얻는 재화를 사용해 공격력, 방어력, 이동속도 등 9가지 기본 스탯을 강화할 수 있습니다.
- **스킬** : 레벨업 시 얻는 스킬 포인트로 스킬 레벨을 올릴 수 있으며, 액티브 스킬은 슬롯에 장착해야 전투에서 자동으로 사용됩니다. 장착된 스킬의 발동 우선순위도 직접 조정할 수 있습니다.
- **장비** : 무기, 방어구, 장신구 3종의 장비를 장착하거나 강화 및 합성해 성장시킬 수 있습니다. 보유하고 있는 장비만으로도 보유 효과가 적용되며, 실제로 장착한 장비는 추가적인 장착 효과까지 부여됩니다.

### 퀘스트 시스템

일일 퀘스트, 반복 퀘스트, 무한 퀘스트 세 가지 유형이 있으며, 일일 퀘스트는 서버 시간을 기준으로 매일 자정에 자동으로 리셋됩니다. 퀘스트를 완료하면 별도의 보상을 받을 수 있어 반복 플레이에 대한 동기를 제공합니다.

### 오디오 시스템

챕터가 바뀌거나 특정 상황(전투 시작, 보스 등장 등)이 발생하면 BGM이 자동으로 전환됩니다. 효과음(SFX)은 EventHub의 이벤트에 연동되어 피격, 스킬 사용, 재화 획득 등 각 상황에 맞게 재생됩니다. 설정 화면에서 BGM과 SFX의 볼륨을 각각 조절할 수 있습니다.

### UI / UX

PopupManager가 팝업의 열기/닫기 스택을 관리하여 여러 팝업이 중첩되어도 올바른 순서로 처리됩니다. 메인 HUD에는 HP, 경험치, 재화 등이 실시간으로 반영되며, 가챠(뽑기) UI와 모바일 조이스틱도 지원합니다.

## 프로젝트 구조 (핵심)

```
Assets/Game/
├── Base/          # 공통 데이터(SO), 매니저 초기화, 세이브/로드
├── Battle/        # 스테이지, 몬스터 스폰, 캐릭터 전투
├── Growth/        # 스탯·스킬·장비·재화 성장 시스템
├── Contents/
│   └── Quests/    # 퀘스트 & 일일 리셋 로직
├── UI/            # 메인 HUD, 팝업, 상점/가챠
└── Audio/         # AudioManager, BGM/SFX 클립
```

### 문규성 — 프로젝트 리드 / 핵심 아키텍처 / 게임 시스템 설계

프로젝트 전반의 구조 설계와 주요 게임 시스템 구현을 담당했습니다. 각 파트가 서로 직접 참조하지 않고도 유기적으로 동작할 수 있도록 `EventHub` 기반 이벤트 아키텍처와 `GameManager` 중심의 초기화 체계를 설계했으며, 스테이지·스탯·보상 등 게임 플레이의 핵심이 되는 시스템들을 직접 구현했습니다.

| 영역 | 상세 내용 |
|------|-----------|
| **프로젝트 기반 구조 설계** | `IGameSystem` / `IManager` 인터페이스를 설계하여 모든 시스템이 `GameManager`에 등록되고 `GetOrder()` 순서에 따라 안전하게 초기화되는 체계를 구축했습니다. 각 파트는 `GameManager.GetGameSystem<T>()`를 통해 다른 시스템을 참조할 수 있어 직접 의존성 없이 협력합니다. |
| **EventHub (이벤트 기반 통신)** | 스테이지 전환, 전투 이벤트, 성장, 퀘스트, UI 반응 등 게임 전반의 이벤트를 한 곳에서 관리하는 `EventHub`를 설계했습니다. 각 파트는 `EventHub`의 이벤트를 구독·발행하는 방식으로 통신하여 파트 간 결합도를 낮추고 독립적인 개발이 가능하도록 했습니다. |
| **실시간 플레이어 스탯 관리** | `StatusCalculator`는 스탯 강화, 장비 보유·장착 효과, 패시브 스킬 효과를 각각 독립적으로 계산한 뒤 합산하여 `RuntimeStatus.finalStatus`에 반영합니다. `EventHub` 이벤트에 바인딩되어 있어 스탯 강화, 장비 변경, 스킬 레벨업 등이 발생하는 즉시 자동으로 재계산되며, 전투 중 모든 데미지·이동속도 계산은 이 `finalStatus`를 기준으로 동작합니다. |
| **스테이지 시스템** | `StageManager`를 구현하여 현재 최고 도달 스테이지를 기준으로 일반 / 도전 / 보스 / 잠금 상태를 자동으로 판별하고 스테이지를 전환합니다. 일반 스테이지에서 사망 시 일정 시간 후 자동 부활, 도전 스테이지에서 실패 시 이전 스테이지로 복귀하는 흐름을 UniTask 기반 비동기로 처리했습니다. |
| **세이브 / 로드 시스템** | 플레이어 진행 데이터(스테이지, 스탯, 스킬, 장비, 재화 등)를 JSON으로 직렬화하여 저장하고, 게임 시작 시 자동으로 로드하는 시스템을 설계했습니다. |
| **오프라인 보상** | 마지막 플레이 시각과 현재 시각의 차이를 계산하여, 게임을 종료한 동안 획득할 수 있었을 골드와 경험치를 자동 지급하는 오프라인 보상 시스템을 구현했습니다. |
| **가챠 시스템** | 확률 테이블(`GachaConfigSO`)을 기반으로 장비를 뽑는 가챠 시스템과 관련 UI를 구현했습니다. |
| **전체 통합 및 빌드** | 각 파트를 단일 메인 씬에 통합하고, Addressables를 활용한 에셋 로딩으로 초기 로딩 최적화를 진행했습니다. 153개의 PR을 생성·머지하며 브랜치 전략과 통합 흐름을 주도했습니다. |

### 김학윤 — 캐릭터 전투 구현 / 스킬 시스템 설계 및 UI 연동

캐릭터가 실제로 움직이고 싸우는 기초 전투 구조와, 스킬을 장착하고 자동으로 사용하는 스킬 시스템 전반을 담당했습니다. 스킬의 데이터 구조 설계부터 실제 발사체/범위 구현, 그리고 UI와의 연동까지 스킬 파트를 일관되게 구축했습니다.

| 영역 | 상세 내용 |
|------|-----------|
| **캐릭터 전투 구현** | 캐릭터의 이동과 공격 기초 로직을 구현했습니다. 자동 전투 환경에서 가장 가까운 적을 탐색하고 공격 범위 내에서 자동으로 공격이 이루어지는 기본 전투 흐름을 설계했습니다. |
| **스킬 구조 설계 및 구현** | 스킬을 `ActiveSkill`, `PassiveSkill`, `ProjectileSkill`, `AreaSkill`, `AreaSkillByProjectile` 등 타입별로 분리하여 확장 가능한 구조로 설계했습니다. 스킬의 장착 → 발동 → 캐스팅 흐름을 `PlayerEquipSkillController`로 관리하며, 슬롯에 장착된 스킬이 우선순위에 따라 자동으로 사용되는 메커니즘을 구현했습니다. |
| **스킬 UI ↔ 데이터 연동** | `SkillManager`와 스킬 UI 간의 양방향 데이터 흐름을 구축했습니다. 스킬 목록 표시, 레벨업 버튼 활성화 조건(스킬 포인트 보유 여부), 장착 변경 팝업 등을 담당하여 플레이어가 스킬을 관리하는 화면 전체를 완성했습니다. |
| **모바일 입력 지원** | 모바일 환경에서 캐릭터를 조작할 수 있는 조이스틱 기능과 관련 프리팹을 구현했습니다. |

### 이종준 — 오디오 시스템 / 적 AI 구현 / 퀘스트 시스템

게임의 분위기를 만드는 오디오 파트와 플레이어를 위협하는 적(보스 포함)의 행동 패턴, 그리고 반복 플레이의 동기가 되는 퀘스트 시스템을 담당했습니다.

| 영역 | 상세 내용 |
|------|-----------|
| **오디오 시스템** | BGM을 직접 제작하고, 맵 전환 이벤트에 맞춰 챕터별 BGM이 자동으로 교체되는 시스템을 구현했습니다. SFX는 특정 상황의 이벤트와 연동하여 자연스럽게 재생되며, 인게임 설정 화면에서 BGM과 SFX 볼륨을 분리해 조절할 수 있는 볼륨 옵션 창도 제작했습니다. |
| **적 AI 및 보스 패턴** | 일반 몬스터의 기본 행동 로직을 구현하고, 보스 몬스터에게는 돌진, 범위 스킬 등 고유한 패턴을 부여했습니다. 보스가 특정 조건에서 스킬을 자동으로 시전하는 AI를 설계했으며, SPUM을 활용해 플레이어와 보스의 전투 모션도 작업했습니다. |
| **퀘스트 시스템** | 일일 퀘스트, 반복 퀘스트, 무한 퀘스트 세 가지 유형의 퀘스트 UI와 로직을 처음부터 끝까지 담당했습니다. 서버 시간 기반 자정 리셋 처리, 퀘스트 완료 판정, 보상 지급 흐름을 완성하고 마지막 폴리싱까지 진행했습니다. |

### 박관규 — UI 레이아웃 설계 및 구현

게임 전반의 UI 화면 레이아웃 설계와 구현을 담당했습니다. 플레이어가 게임 내에서 접하는 대부분의 화면을 제작했으며, 개발 기간 내내 팀원들의 기능 구현에 맞춰 UI를 지속적으로 갱신하고 개선했습니다.

| 영역 | 상세 내용 |
|------|-----------|
| **메인 화면 및 팝업 UI** | 게임을 처음 실행했을 때 나타나는 메인 화면과 각종 팝업 창의 레이아웃을 제작했습니다. 버튼 배치, 정보 표시 구조 등 플레이어가 처음 접하는 인터페이스의 전체적인 형태를 잡았습니다. |
| **성장 관련 UI** | 스탯 강화창(능력치 강화), 스테이지 선택 화면, 장비 관리 창 등 플레이어의 성장과 직결되는 화면들을 구현했습니다. 강화 횟수, 현재 스탯 수치, 장비 슬롯 상태 등을 알아보기 쉽게 표시하는 레이아웃을 제작하고, 버그를 직접 수정해 완성도를 높였습니다. |
| **에셋 제작 및 UI 개선** | 장비 이미지, 캐릭터 이미지 등 게임에 사용되는 비주얼 에셋을 추가하고 교체했습니다. 기능 개발이 진행되는 동안 각 화면의 UI를 꾸준히 다듬어 전체적인 완성도를 유지했습니다. |
