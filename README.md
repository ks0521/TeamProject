## 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 장르 | 2D 자동 전투 RPG |
| 엔진 | Unity 2022.3.62f3 (URP) |
| 개발 기간 | 2026.03.03 ~ 2026.04.15 (약 6주) |
| 팀 규모 | 4인 |
| 핵심 컨셉 | 방치형 자동 전투 + 스테이지 돌파 + 성장(스탯 / 스킬 / 장비) + 퀘스트 |

> **구조적 목표** : SO 기반 데이터 설계, Manager 초기화 체계, EventHub 이벤트 연동을 통해 기능 간 결합도를 낮추고 라이브 서비스 확장이 가능한 아키텍처를 지향했습니다.

## 주요 기능

### 스테이지 전투 시스템
- 일반 / 도전 / 보스 스테이지 분기 처리
- 몬스터 오브젝트 풀 기반 스폰 · 처치 · 클리어/실패 처리
- 보스 고유 패턴 (돌진, 광역 스킬, 자동 스킬 시전)

### 보상 시스템
- 일반 스테이지에서 적 처치 시 드랍테이블 기반 보상획득
- 도전 / 보스 클리어 시 클리어보상 획득
- 오프라인 접속 보상 자동 계산(최대 8시간)

### 성장 시스템
- **스탯** : 사냥시 얻는 재화를 통한 기본스탯 강화 가능
- **스킬** : 레벨업시 얻는 스킬포인트를 사용하여 스킬레벨 성장가능. 액티브 스킬은 스킬슬롯에 장착 시 사용가능
- **장비** : 장착 · 강화 · 합성을 통한 성장, 무기 / 방어구 / 장신구 3종의 장비 존재. 가챠 시스템 이용하여 장비획득 가능

### 퀘스트 시스템
- 일일 / 반복 / 무한 퀘스트 구조
- 서버 시간 기반 일일 퀘스트 자동 리셋

### 오디오 시스템
- 챕터별 BGM 자동 전환
- 이벤트 기반 효과음(SFX) 연동

### UI / UX
- 팝업 매니저를 통한 계층적 팝업 관리
- 메인 HUD 실시간 스탯 반영
- 모바일 환경 지원(Android)

## 프로젝트 구조 (핵심)

```
Assets/Game/
├── Base/          # 공통 데이터(SO), 매니저 초기화, 세이브/로드
├── Battle/        # 스테이지, 몬스터 스폰, 캐릭터 전투
├── Growth/        # 스탯·스킬·장비·재화 성장 시스템
├── Contents/
│   └── Quests/    # 퀘스트 & 일일 리셋 로직
├── UI/            # 메인 HUD, 팝업, 상점/가챠
└── Audio/         # AudioManager, BGM/SFX 클립
```

---

## 실행 방법

1. Unity Hub에서 프로젝트 폴더를 추가합니다.
2. **Unity 2022.3.62f3** 버전으로 엽니다.
3. `Assets/Game/Scenes/MainScene.unity` 씬을 실행합니다.

## 팀원 소개 및 역할


---

### 문규성 - **프로젝트 리드 / 핵심 아키텍처**

| 영역 | 주요 작업 |
|------|-----------|
| **메인 프레임워크 구현** | `GameManager` 초기화 체계 구축, SO 딕셔너리 설계, `EventHub` 이벤트 연동, `Addressables` 로딩 파이프라인 |
| **스테이지 시스템** | `StageManager` 구현, 일반/도전/보스 스테이지 분기, 몬스터 오브젝트 풀,  아이템 드랍 로직 설계|
| **이벤트 기반 통신** | 게임 전반적인 이벤트를 관리하는 `EventHub` 구현, 각 파트별 이벤트 구독,발행 설계 |
| **세이브 / 로드** | JSON 기반 `SaveData` 구조 설계, 게임 시작 시 자동 로드, `PlayerPrefs` 연동 |
| **실시간 플레이어 스탯 관리** | 스탯 · 장비 · 스킬 효과 계산 자동화 |
| **장비 시스템** | 장비창 UI 최적화, `Dictionary` 기반 장비 빠른 조회 구현 |
| **오프라인 보상** | 비접속 시간 계산 로직 구현 및 보상 팝업 처리 |
| **통합 / 배포** | 파트 통합 씬 완성, 빌드파일 배포 |
